Política de privacidad de NuvPrivacity

Última actualización: 6 de octubre de 2026

1. Identificación

NuvPrivacity es una aplicación de mensajería privada. Para consultas sobre privacidad, datos personales o eliminación de cuenta puedes contactar a:

el_cruel1925@hotmail.com

2. Información que tratamos

NuvPrivacity puede tratar información necesaria para proporcionar sus funciones, incluyendo identificadores de usuario, perfiles, configuración, conversaciones, mensajes, archivos y datos relacionados con grupos y llamadas cuando el usuario utiliza esas funciones.

3. Cámara, micrófono y archivos

La aplicación puede solicitar acceso a la cámara, micrófono y archivos del dispositivo cuando una función requiere esos permisos, por ejemplo para enviar fotografías, archivos o mensajes de audio.

4. Uso de la información

  • Proporcionar las funciones de mensajería.
  • Administrar cuentas y conversaciones.
  • Permitir el envío de mensajes y archivos.
  • Proteger la seguridad del servicio.
  • Gestionar reportes y bloqueos.
  • Procesar funciones premium.
  • Cumplir obligaciones legales.

5. Compartición de información

NuvPrivacity no vende los datos personales de los usuarios. La información puede ser procesada por proveedores técnicos necesarios para operar el servicio, incluyendo infraestructura de base de datos, almacenamiento y autenticación.

6. Seguridad

Aplicamos medidas técnicas razonables para proteger la información y utilizamos conexiones seguras para la comunicación con nuestros servicios.

7. Conservación de datos

La información se conserva mientras sea necesaria para prestar el servicio, mantener la seguridad, cumplir obligaciones legales o resolver disputas.

8. Eliminación de cuenta

Los usuarios pueden solicitar la eliminación de su cuenta mediante el mecanismo disponible en NuvPrivacity o mediante nuestro recurso web de eliminación de cuenta.

Solicitar eliminación de cuenta

9. Privacidad de menores

NuvPrivacity no está diseñada para recopilar deliberadamente información personal de menores de una forma que infrinja las leyes o políticas aplicables.

10. Cambios

Esta política puede actualizarse cuando cambien las funciones del servicio o nuestras prácticas de tratamiento de datos.
